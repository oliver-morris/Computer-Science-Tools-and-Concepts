### First Project
1. download dependencies and run the server
2. create a Dockerfile and .dockerignore
3. write the instructions for how to run the server in the dockerfile
4. docker build -t project-name .
5. docker run -p PORT:PORT project-name

Additional:

you can run vulnerability checker using docker scout in terminal or in docker desktop under the image
