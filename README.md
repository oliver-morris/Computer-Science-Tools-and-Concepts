# Computer Science — Tools & Concepts

A collection of notes, explanations, examples, and resources for learning **computer science concepts, technologies, tools, and software engineering practices**.

This repository is intended to be a practical reference for understanding how things work, experimenting with them, and building a stronger foundation across different areas of computer science.

> **Learn → Understand → Experiment → Build**

## 🎯 Goals

The goal is not simply to collect definitions, but to **understand concepts by implementing and experimenting with them**.
This repository is a long-term learning project focused on:

* Building strong computer science fundamentals
* Understanding how modern technologies work under the hood
* Learning new tools through practical experimentation
* Implementing concepts rather than only reading about them
* Creating small projects to reinforce understanding
* Developing useful reference material for future projects
* Exploring areas outside of my primary specialisation


## 🤝 Philosophy

> **Don't just learn how to use the tool. Learn why it exists, how it works, and what happens underneath it.**

Whenever possible, I recommend using the available resources linked at the bottom of each repository to view examples and run through some of the practice scenarios with them.

This repository is continuously evolving as new technologies, concepts, experiments, and resources are added.
